🔥 Promoções Automáticas

Como as promoções funcionam

  • As promoções são aplicadas automaticamente no carrinho, sem o cliente precisar digitar cupom.
  • Se mais de uma promoção estiver válida ao mesmo tempo, o sistema aplica a mais vantajosa para o cliente.
  • Em empate de desconto, a prioridade define qual promoção vence.
  • Se a promoção estiver marcada como acumulável, ela pode somar com um cupom válido.
  • Quando a promoção não for acumulável, o carrinho usa apenas o melhor desconto entre cupom e promoção.
